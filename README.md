# 🌙 Sleep Mode — Connections App

An Android app that automatically replies to callers when you're asleep, so you don't have to choose between "always reachable" and "getting woken up for nothing."

## The idea

Most people keep their phone ringer on all night "just in case it's urgent" — and end up getting woken up by calls that could've waited. This app solves that: when Sleep Mode is on, anyone who calls you during your sleep hours instantly gets an auto-reply SMS letting them know you're asleep and can decide for themselves whether to call back.

## Features

- 🌗 **Sleep Mode toggle** — turn it on/off manually
- ⏰ **Custom sleep hours** — set your own start and end time (not hardcoded)
